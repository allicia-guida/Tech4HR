# Termos de Uso do Tech4HR

Esta é uma minuta para revisão jurídica.

O acesso ao Tech4HR é pessoal e deve utilizar as credenciais fornecidas pela organização. O usuário é responsável por proteger o aparelho e comunicar acessos indevidos.

Registros de jornada somente serão considerados oficiais quando confirmados pelos serviços corporativos. Tentativas realizadas sem conexão não devem ser interpretadas como registros concluídos.

É proibido alterar o aplicativo, falsificar informações, utilizar credenciais de terceiros ou tentar contornar controles de segurança.

A organização deverá definir canais de suporte, procedimentos de contestação, disponibilidade do serviço e regras específicas da relação de trabalho.
